# Product Requirements Document: Us & Me

## 1. 项目背景
解决亲密关系中“共同记录”与“独立空间”共存的需求，同时通过“家庭小餐馆”等趣味功能增加生活情趣。

## 2. 用户画像
* **User A (Me)**: 开发者，理性，需要记录工作和个人想法，不想被对方时刻窥探。
* **User B (Partner)**: 伴侣，感性，喜欢互动，希望能看到对方的关注和付出。

## 3. 核心概念
* **Twin Spaces (双子星)**: 全局开关，切换“We Mode (公共)”和“Me Mode (私密)”。
* **Family Group**: 两人绑定为一个家庭单元，数据共享基于此ID（后续可考虑多人）。

## 4. 功能列表 (Feature List) - MVP阶段

### P0: 核心功能 (Must-have)
| 模块 | 功能点 | 描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **Auth** | 用户注册/登录 | 基础账号体系，支持家庭绑定。 | P0 |
| **Bistro** | 菜谱录入 | 上传菜名、图片、所需积分/价格。 | P0 |
| **Bistro** | 点餐/接单 | 对方点单后，大厨收到状态更新，可接单/拒单。 | P0 |
| **Common** | 首页Dashboard | 展示今日心情、今日菜单、家庭积分。 | P0 |

### P1: 重要功能 (Should-have)
| 模块 | 功能点 | 描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **System** | 积分系统 | 做家务+积分，点餐-积分。 | P1 |
| **Space** | 私密日记 | 仅自己可见的 Markdown 编辑器。 | P1 |

### P2: 锦上添花 (Nice-to-have)
| 模块 | 功能点 | 描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| **Memory** | 时光相册 | 时间轴展示照片。 | P2 |
| **Bistro** | 吃什么转盘 | 随机决定吃什么。 | P2 |

## 5. 非功能需求
* **隐私性**: 私密数据必须在数据库层级（RLS）进行物理隔离。
* **响应速度**: 尤其是点餐通知，需低延迟（使用 Realtime）。
