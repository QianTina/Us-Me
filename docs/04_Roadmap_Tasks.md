# Project Roadmap & Backlog

## Phase 1: 骨架与菜单展示 (Day 1-3)
**目标**: 让 App 跑起来，并能看到菜单。

- [ ] **初始化**: 使用 Next.js + Tailwind + Shadcn 初始化项目
- [ ] **配置**: 配置 `tailwind.config.ts` (新粗野主义颜色/阴影)
- [ ] **数据库**: Supabase 建表 (`profiles`, `menu_items`)
- [ ] **页面**: 菜单列表页 (从数据库拉取数据并展示)
- [ ] **功能**: 新增菜品弹窗 (包含 Supabase Storage 图片上传)

## Phase 2: 交互与订单 (Day 4-7)
**目标**: 让菜单能用（可以点餐）。

- [ ] **数据库**: 创建 `orders` 表
- [ ] **交互**: 菜单卡片实现 "点餐" 按钮逻辑
- [ ] **页面**: "后厨视图" (订单管理面板)
- [ ] **功能**: 订单状态流转 (待接单 -> 烹饪中 -> 上菜)
- [ ] **实时性**: 接入 Supabase Realtime 实现新订单弹窗通知

## Phase 3: 双子星逻辑 (Day 8-10)
**目标**: 实现 Me/We 切换与隐私保护。

- [ ] **交互**: 全局 "We/Me" 切换开关组件
- [ ] **样式**: 根据模式动态切换全局主题色 (绿/紫)
- [ ] **功能**: 私密日记模块 (CRUD)
- [ ] **安全**: 实施 RLS (行级安全策略) 确保数据隐私隔离

## Phase 4: 游戏化与润色 (Day 11-14)
**目标**: 加入经济系统与最终打磨。

- [ ] **功能**: 积分扣除逻辑 (点餐消耗)
- [ ] **功能**: 任务看板 (做家务赚积分)
- [ ] **UI**: 移动端适配检查与细节润色
- [ ] **部署**: Vercel 生产环境部署与域名绑定
